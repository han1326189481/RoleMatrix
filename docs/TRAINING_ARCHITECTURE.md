# RoleMatrix 小R 训练与运行架构

## 一、核心设计思路：大脑 + 嘴巴 双层架构

小R的对话生成不是单模型直接输出，而是模仿真人"想好再说"的过程：

```
用户消息
  ↓
┌─────────────────────────────────────────┐
│  本地模型 (Qwen2.5:7B LoRA) = 大脑      │
│  职责：                                 │
│  1. 检索用户画像（是谁、喜欢什么）        │
│  2. 回忆历史对话（context/memory）       │
│  3. 预测情绪变化（7维向量）              │
│  4. 组织要说的内容（要点 + 风格策略）     │
└─────────────────────────────────────────┘
  ↓ 把"想好的话"作为提示
┌─────────────────────────────────────────┐
│  DeepSeek API = 嘴巴                    │
│  职责：                                 │
│  1. 拿到大脑给出的要点 + 风格            │
│  2. 生成自然流畅的最终回复               │
│  3. 拆分成多条短消息（模拟打字发送）      │
│  4. 生成过程中可反问大脑具体细节          │
└─────────────────────────────────────────┘
  ↓
用户收到回复
```

## 二、为什么这样设计

### 真人对话模拟
- 真人说话前会"想一下"：回忆上次聊了啥、判断对方情绪、组织语言
- 本地模型就是"想一下"的过程，DeepSeek 是"开口说"的过程
- 不追求回复速度，追求真实感

### 本地模型价值
- 隐私：用户画像、历史记忆不出本机
- 成本：大脑做的是结构化决策（不是生成大段文字），token 消耗低
- 可控：情绪/记忆/策略都是结构化输出，Python 代码可校验

### DeepSeek 价值
- 文笔好：大模型生成自然语言比 7B 本地模型强
- 风格统一：只要给对 prompt，输出稳定
- 可反问：生成时遇到不确定的细节，调用本地模型查询

## 三、训练目标（本轮）

### 训练对象
本地模型 Qwen2.5:7B-Instruct，通过 LoRA 微调

### 训练数据
`data/datasets/cleaned/rolematrix_sft_final.jsonl`（1765 条）
- 20 条真实对话提取（11.txt/22.txt）
- 77 条清洗对话
- 170 条 adorable-high-eq 风格
- 1498 条仿写变体（9 场景 × 随机变换）

### 数据格式
ShareGPT 格式，每条含：
- system：人格 + 7 维情绪向量
- human/gpt 多轮交替

### 训练目标
让本地模型学会小R的说话风格：
- 短句拆分、语气词、省略号、偶尔结巴
- 口头禅：韩哥/bro/okk/好嘟/我滴妈/我去/噗哈哈哈
- 撒娇依赖、小傲娇、温暖关心、会闹小情绪
- 技术不太好的计算机系女大学生形象

## 四、训练参数（QLoRA）

### 硬件
- GPU: RTX 4060 Laptop (8GB VRAM)
- 4-bit 量化基模 + LoRA adapters

### 关键参数
- base_model: Qwen2.5-7B-Instruct (Q4)
- lora_rank: 16
- lora_alpha: 32
- learning_rate: 2e-4
- batch_size: 1 (with gradient accumulation 4)
- max_seq_length: 1024
- epochs: 3
- target_modules: q_proj, k_proj, v_proj, o_proj, gate_proj, up_proj, down_proj

## 五、运行时流程（训练后）

```
用户发送消息 "韩哥我今天好累"
  ↓
1. 本地模型接收：
   - 用户消息
   - 当前情绪状态
   - 最近 10 轮对话
   - 用户画像
  ↓
2. 本地模型输出结构化决策（JSON）：
   {
     "emotion_delta": {"tired": +5, "happy": -3, "want_chat": +10},
     "memory_recall": "用户最近在赶大作业",
     "reply_plan": {
       "tone": "gentle_care",
       "points": ["关心累的原因", "提议一起休息"],
       "length": "short"
     }
   }
  ↓
3. Python 代码组装 DeepSeek prompt：
   system = 人格 + 风格策略 + 禁语清单
   user = reply_plan + 用户原话
  ↓
4. DeepSeek 生成回复：
   "咋啦咋啦 大作业弄完了嘛…别太拼了
    要不歇会儿？我陪你"
  ↓
5. 后端切分回复（split_reply）
  ↓
6. 前端分段显示 + 打字延迟
  ↓
用户收到回复
```

## 六、DeepSeek 反问大脑机制

DeepSeek 生成时，如果遇到不确定的细节（用户提到的某件事的细节），可以暂停生成，调用本地模型查询：

```
DeepSeek: "你上次说那个…[需要查询用户上次提到的具体事]"
  → 调用本地模型："用户上次提到的是什么具体的事？"
  → 本地模型返回："用户上次说在赶数据库大作业，截止下周三"
  → DeepSeek 继续生成："你上次说那个数据库大作业 弄完没？"
```

这通过 function calling 实现：
- DeepSeek 调用 `query_memory(detail)` 函数
- 函数后端调用本地模型
- 返回结果给 DeepSeek 继续生成

## 七、本地模型结构化输出训练（下一步）

当前轮次训练的是小R的"说话风格"。下一步需要训练本地模型做"结构化决策"：

### 数据格式
```json
{
  "instruction": "你是小R的大脑...",
  "input": {
    "user_message": "韩哥我今天好累",
    "emotion_state": {...},
    "history": [...]
  },
  "output": {
    "emotion_delta": {...},
    "memory_recall": "...",
    "reply_plan": {...}
  }
}
```

### 评估指标
- 情绪预测方向正确率
- 记忆引用相关性
- 回复策略合理性
